#  Фреймворк Автоматизированного Тестирования CitySoft

## Задача Проекта

Данный проект представляет собой **гибридный фреймворк** для комплексного тестирования веб-приложения, обеспечивая покрытие на двух уровнях:

* **UI (User Interface)**: Функциональное тестирование пользовательского пути (вход, поиск, работа с элементами фильтрации).
* **API (Application Programming Interface)**: Проверка бизнес-логики, валидации данных и аутентификации на серверном уровне.

---

## Технологический Стек

| Инструмент | Категория | Назначение |
| :--- | :--- | :--- |
| **pytest** | Ядро | Основной тестовый фреймворк. |
| **selenium** | UI | Инструмент для UI-автоматизации. |
| **requests** | API | Библиотека для выполнения HTTP-запросов. |
| **allure** | Отчетность | Генерация наглядных и детальных отчетов. |
| **python-dotenv** | Конфигурация | Загрузка переменных окружения из файла `.env`. |
| **pytest-rerunfailures** | Надежность | Плагин для **повторного запуска** нестабильных тестов. |
| **pytest-repeat** | Производительность | Плагин для многократного запуска тестов ($N$ раз независимо от их результата). Используется для стресс-тестирования или проверки общей стабильности. |
| **pytest-xdist** | Производительность | Плагин для **параллельного запуска** тестов. |

---

## Структура Проекта

| Директория | Содержание | Назначение |
| :--- | :--- | :--- |
| **`./tests/test_ui`** | Тестовые файлы (`test_*.py`) для взаимодействия с браузером. | Проверка пользовательского опыта (Login, Map actions). |
| **`./tests/test_api`** | Тестовые файлы для проверки конечных точек API. | Проверка статусов, схем JSON и бизнес-логики. |
| **`./src/pages`** | Реализация **Page Object Model (POM)**. | Инкапсуляция логики UI-элементов (`LoginPage`, `MapPage`). |
| **`./src/api`** | **API Clients** и хелперы. | Инкапсуляция логики запросов, заголовков и общих проверок API. |
| **`./data`** | Все тестовые данные. | Локаторы UI, шаблоны JSON для API, негативные сценарии, данные для параметризации. |
| **`./conftest.py`** | Глобальные и локальные фикстуры Pytest. | Определение фикстур (драйвер, клиенты, авторизация Cookie). |
| **`.env`** | Переменные окружения. | Хранение секретных данных (логины, пароли, URL). |

## Запуск Тестов

### 1. Подготовка

1.  **Клонирование репозитория:**
    ```bash
    git clone https://github.com/Svetoch09/CitySoft_automation.git
    cd CitySoft_automation
    ```

2.  **Создание виртуального окружения и установка зависимостей:**
    ```bash
    python -m venv .venv
    .\.venv\Scripts\activate
    pip install -r requirements.txt
    ```

3.  **Конфигурация (файл `.env`)**: Необходимо скопировать `.env.template` в `.env` и заменить заглушки реальными данными.

### 2. Команды Запуска

Используйте команду `pytest` с необходимыми флагами.

#### а. Основной Запуск с Отчетом

Запустить все тесты и сгенерировать сырые данные Allure:

```bash
pytest --alluredir=./allure_results
```

#### б. Расширенные Опции
Запустить только UI-тесты:
```bash
pytest -m ui
```
Запустить только API-тесты:
```bash
pytest -m api
```
Запустить все тесты, повторяя **неудачные** до N раз:
```bash
pytest --reruns N
```
Запустить тесты в N параллельных потоках:
```bash
pytest -n N
```
Запустить тесты N раз:
```bash
pytest --count N
```

#### в. Генерация Отчетов Allure
Очистка старых данных и генерация нового HTML-отчета
```bash
allure generate ./allure_results --clean 
```
Открытие HTML-отчета в браузере
```bash
allure open
```
